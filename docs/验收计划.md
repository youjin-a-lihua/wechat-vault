## 已知问题与取舍

1. **vol3(btrfs) 上 SQLite 写偶发 disk I/O error**（root cause 未深究，现象为建库后读 sqlite_master 即 I/O error；FTS5 单测正常，怀疑 fs 交互偶发）——**绕过方案**：归档到 /tmp(vol2 overlay) 完成后整文件拷回 /data。
2. **微信「退出登录」= 进程退出**：无法 attach 已登录进程等重登，passphrase 抓取必须"tracer 启动 + 用户点登录"。
3. **wxextract render 的单库限制**：每联系人只绑定第一个找到的库的 Msg_ 表（86% 消息漏渲染）——已用自研 v3 导出器绕过。
4. **PWA/SW 在局域网 IP 不安全上下文不可用**——设计取舍（隐私红线禁止公网 HTTPS）。
5. 图片 V2 解密的 image AES key 优先从**消息 JSONL 的 media.aeskey** 取（微信 CDN 密钥），失败再从进程内存提取。
